# Contributing

[简体中文](CONTRIBUTING.md)

CellMotion welcomes bug reports, focused feature proposals, and code contributions. Search existing issues and pull requests before opening a new one.

## Open an issue

1. Choose **Issues → New issue** and select **Bug report** or **Feature request**, or use the [issue form](https://github.com/opc8838-hub/font-animation/issues/new/choose).
2. For a bug, include the effect or editor URL, browser and device, reproduction steps, actual and expected results, and whether Chinese text, canvas size, or export is involved.
3. Add a screenshot or short recording when useful. Include relevant browser-console errors as text. Never include passwords, tokens, or private assets.
4. For a feature request, explain the problem, desired behavior, and use case. Share reference media only when you have permission to do so.

## Open a pull request

1. Create a focused branch from the latest `main`. Contributors outside the repository should fork it and open a PR from their fork.
2. Keep each PR to one related change and link its issue (for example, `Closes #123`).
3. Open **Pull requests → New pull request**, target `main`, complete the PR template, and submit it for review.
4. Describe what changed, why, and how you verified it. Include desktop and mobile screenshots for UI work; list playback and export checks for motion work.
5. Preserve third-party attribution and licenses. For added fonts, images, videos, or other large files, state the source and usage rights. Do not commit secrets, personal information, or assets you cannot publish.
