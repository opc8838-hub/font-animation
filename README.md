# ME Motion Studio —— 文字 × 图像动效工作室

原站 [spacetypegenerator.com](https://spacetypegenerator.com)（kielm 开源项目，p5.js 实现）的本地中文版。
**40 个字体动效 + 中文渲染 + 多图片与文字混排 + 浏览器本地抠图 + 响应式创作工作台。**

在线浏览：[GitHub Pages](https://opc8838-hub.github.io/font-animation/gallery.html)

开发新动效前请阅读：[参考视频拆解与动效开发工作流](docs/REFERENCE_VIDEO_WORKFLOW.md)。分析结果可从 [`docs/analyses/TEMPLATE.md`](docs/analyses/TEMPLATE.md) 创建；编码代理还会自动读取根目录 [`AGENTS.md`](AGENTS.md) 中的项目约束。

## 快速运行

```bash
# 双击 C:\Users\Administrator\stg_cn\启动中文版.bat
# 或手动：
cd C:\Users\Administrator\stg_cn\site
python -m http.server 8080
# 浏览器打开 http://127.0.0.1:8080/gallery.html
```

> 必须走 HTTP 服务（p5.js `loadFont` 禁止 file:// 直接打开）。

## 2026-08-08 动效编排升级

### Flash 拆分

- `site/flash-scenes.html` 是 Flash 的子风格库，将原本随机混合的 13 个场景拆成独立入口。
- 每个子风格通过查询参数独立访问，例如 `flash.html?scene=halo`、`flash.html?scene=split`。
- 所有入口共享原来的场景类，不复制动画源码；修复某个场景时只需维护一份代码。
- `flash.html` 的“场景”面板也可直接切换单一子风格，选择“随机混合”即可恢复原版行为。

### 图片 / 图形与文字编排

Flash、Snap、Construct 新增共享媒体层，支持上传 PNG、JPG、WebP、SVG、GIF，也可直接使用圆形、方形、三角形、星形、药丸形和圆环。

- 通用控制：前后图层、水平/垂直位置、大小、宽高比、旋转、透明度、动效速度。
- 同步动效：弹入、左侧滑入、底部滑入、旋转、呼吸、漂浮、环绕。
- Flash：媒体层与每个子场景共享节拍，场景切换时一起重新开始。
- Snap：选择“作为一个字”，在文字中插入 `{图}`；媒体会继承相邻字的位移、拉伸和错切。
- Construct：选择“自动穿插在文字间”；上传图片会替换原有随机 GIF 占位，作为真实排版元素参与波形动画。
- 共享实现位于 `site/media-layer.js` 和 `site/media-layer.css`。

### 双栏编辑工作台

- Flash、Snap、Construct 的桌面版改为固定双栏：左侧 360px 编辑器，右侧独立效果画布。
- p5 画布读取右侧工作区的真实尺寸，动画中心、图片坐标和响应式缩放不再把左侧面板算进画布。
- 编辑器和画布之间使用实体分界线，任何控件都不会覆盖动画内容。
- 点击底部开关收起编辑器后，画布会自动扩展至全屏并重新计算尺寸。
- 640px 以下继续使用手机底部编辑面板，避免横向空间不足。

### 精准内联与本地去背景

- Flash、Snap、Construct 都可在文字输入框的任意光标位置插入 `{图}`，也支持复制、移动或插入多个标记。
- 插入按钮会自动启用媒体和内联排版，不再要求用户额外切换“结合方式”；输入框中的 `{图}` 仅是编辑定位符，画布对应位置渲染真实图片。
- Flash 将图片标记直接写入场景文字纹理，图片会随弯曲、切分、百叶窗、扭转等 13 个独立场景共同变形。
- Snap 按字符位置重排，图片继承所在字符的位移、拉伸和错切。
- Construct 检测到显式 `{图}` 后进入精确排版模式，停止随机插入装饰，确保图片严格位于标记位置。
- 内联图片可调整相对字号、文字基线和左右留白，使主体与字面高度和字距贴合。
- 静态图片上传后默认在浏览器本地去除白底；可修改背景颜色、容差和边缘羽化，整个处理过程不会上传图片。
- “保护主体内部的白色”默认开启：只把与图片边缘连通的背景加入蒙版，先以绿幕显示将被删除的范围，再生成透明结果，避免主体内部的白色被全局色键误删。
- 自动去背景适合白底、纯色底和近似纯色底；若主体与背景在边缘完全同色，仍需 AI 主体分割或人工蒙版；GIF 保留原动画，不执行逐帧去背景。

### 轻量动效工作台

- Flash、Snap、Construct 不再沿用原站的荧光色长表单，统一为 420px 系统灰检视器与独立黑色预览台；使用系统字体、白色参数卡和单一蓝色操作色。
- 左侧编辑器始终独立纵向滚动，提供可见原生滚动条和可拖动的滚动进度滑块；窄窗口下仍能滚到全部媒体与导出设置。
- 画布底部新增“隐藏 / 显示编辑器”和“暂停 / 播放”控制；焦点不在输入控件时，也可以用空格键暂停或继续。
- 内联模式只显示真正相关的参数；图片可按文字字号的 25%–300% 缩放，并可调整基线、文字间距、宽高比、旋转和透明度。
- 高分屏预览固定使用 1× 像素密度；静态上传图提供流畅 1200px、高清 2048px、超清 3200px 三档纹理质量，默认高清；滑动内联参数时采用短延迟合并重建，降低大图上传后的持续掉帧。

## ⚠️ 关键坑（改代码前必读）

- **textarea 的 id 不要统一改**：有的效果代码用 `getElementById("textArea")`（大写 A），有的用 `select("#textfield")`。改 id 会直接弄挂页面。当前已各就各位。
- **第三方库不要翻译**：`CCapture.all.min.js`、`js/gif.worker.js` 是压缩第三方库，已从原站恢复原版。任何批量文本替换都要排除它们（`translate_js.py` 已排除 p5/CCapture/gif.worker）。
- **字体用 TTF 不用 OTF**：p5.js `textToPoints` 对 CFF/OTF 轮廓有兼容问题。
- **旧版控件变量名不要随意改**：共享编辑层会根据 p5 控件对应的全局变量名生成中文标签；改名后功能仍可能运行，但标签会退回为通用“参数”。
- **不要用程序化 click 展开现代面板**：部分 p5 效果把页面任意点击当作画布交互；应直接设置折叠区状态，避免触发动画函数。
- **CDN 依赖**：页面引用了 cdnjs 的 p5.js 等，目前需要联网加载。要做完全离线需本地化这些 CDN 文件（见待办）。
- **子集化前先备份**：字体裁剪后建议用 `textToPoints` 测试目标文字，防止字形丢失。
