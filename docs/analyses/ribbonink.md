# 流彩笔迹（Ribbon Ink）运动分析

## 证据范围

- 用户录屏：H.264，720×1556，30 FPS，273 帧；有效 16:9 内容区域为 720×405。
- 正常速度决定循环节奏；10 FPS 与 30 FPS 密集切帧用于确认写入、纹理流动和擦除顺序。
- 手机播放器界面、悬浮辅助按钮和录屏留白不属于动效。

## 可见证据

| 时间段 | 观察 | 实现约束 |
| --- | --- | --- |
| 约 0.00–0.50 秒 | 彩色笔触从左下进入，沿同一手写轨迹向右完成 | 左到右路径写入，不用整体平移或透明度伪装 |
| 约 0.50–1.37 秒 | 外轮廓基本稳定，深紫纹理沿粉色笔触内部持续移动 | 轮廓与纹理分离；纹理由确定性时间驱动 |
| 约 1.37–1.94 秒 | 左侧先消失，右侧尾笔最后离场 | 擦除和写入同方向，使用同一弧长窗口 |
| 约 1.94–2.50 秒 | 只剩静态黑色 `TIME` | 无残影、缩放或透明尾巴 |

## 冻结运动契约

- 静态黑色大写底字始终存在。
- 彩色层是一个连贯的小写手写 `time` 笔势，包含独立横笔与圆点，但共享同一写入/擦除事件窗口。
- 循环长度 2.50 秒：写入 0.50 秒、完整流动 0.87 秒、擦除 0.57 秒、底字停留 0.56 秒。
- 写入与擦除均从左向右；擦除不是反向回卷。
- 彩色外轮廓在完整阶段冻结，只有内部纹理运动。
- 预览、PNG、GIF 和 MP4 必须调用同一个 `renderFrame(time, width, height)`。

## 实现选择

- 默认 `TIME` 使用专门绘制的贝塞尔中心线、变宽圆头笔触与弧长采样。
- 深紫纹理由多个沿弧长移动的短带组成，使用固定公式而不是随机帧状态。
- 其他文字使用独立的通用彩色手势线，不把彩色文字副本硬叠在底字上。
- “琴弦”效果仅提供了曲线带状网格与弧长纹理映射的研究方向；本效果重新实现几何和时间逻辑，没有复制其 p5 源码。

## 验证记录

- 浏览器冻结检查：0.25、0.70、1.65、2.10 秒分别对应半写入、完整、半擦除和纯底字。
- 真实 PNG：720×406，与同时间预览一致。
- 真实 GIF：720×406，38 帧；使用 60/70ms 帧延迟分配后，FFmpeg 实测 2.50 秒。
- 真实 H.264 MP4：720×406，30 FPS，75 帧，FFprobe 实测 2.500 秒。
- 已检查 16:9、1:1 和 9:16 舞台，以及中文、日文、韩文字体回退。
- 已检查方案保存、导入、清理重做、恢复默认和自动保存。
