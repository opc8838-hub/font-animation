# 流彩笔迹（Ribbon Ink）运动分析

## 证据范围

- 用户录屏：H.264，720×1556，30 FPS，273 帧；有效 16:9 内容区域为 720×405。
- 正常速度决定循环节奏；10 FPS 与 30 FPS 密集切帧用于确认写入、纹理流动和擦除顺序。
- 手机播放器界面、悬浮辅助按钮和录屏留白不属于动效。

## 可见证据

| 时间段 | 观察 | 实现约束 |
| --- | --- | --- |
| 约 0.00–0.50 秒 | 彩色笔触从左下进入，沿同一手写轨迹向右完成；`i` 点在写入末段独立出现 | 保留逐帧写入次序，不用整体平移或透明度伪装 |
| 约 0.50–1.37 秒 | 外轮廓基本稳定，深紫纹理沿粉色笔触内部持续移动 | 轮廓与纹理分离；纹理由确定性时间驱动 |
| 约 1.37–1.94 秒 | 左侧先消失，右侧尾笔最后离场 | 擦除和写入同方向，使用同一弧长窗口 |
| 约 1.94–2.50 秒 | 只剩静态黑色 `TIME` | 无残影、缩放或透明尾巴 |

## 冻结运动契约

- 静态黑色大写底字始终存在。
- 彩色层是一个连贯的小写手写 `time` 笔势；`i` 点在写入末段独立出现，点内深紫纹理和主笔迹保持同一流动材质。
- 循环长度 2.50 秒：写入 0.50 秒、完整流动 0.87 秒、擦除 0.57 秒、底字停留 0.56 秒。
- 写入与擦除均从左向右；擦除不是反向回卷。
- 彩色外轮廓在完整阶段冻结，只有内部纹理运动；`i` 点位置不漂移，内部色块持续变化。
- 预览、PNG、GIF 和 MP4 必须调用同一个 `renderFrame(time, width, height)`。

## 实现选择

- 使用一张 1672×941 的透明笔迹母版锁定完整外轮廓；母版只提供透明度，不包含底字、背景或时间帧。
- 贝塞尔中心线以累计弧长驱动写入和擦除蒙版；完整阶段直接显示冻结的母版轮廓，避免窄路径裁掉回环。
- 五色流纹沿同一中心线连续移动，并始终裁切在母版透明度内。文字、颜色、尺寸或导出变化不会切换另一套渲染器。
- `i` 点从母版独立分层，使用单独的延迟弹入、内部旋流与提前收束；位置不漂移。
- 黑色底字最后绘制，保持原片的前后遮挡。编辑底字只改变文字层，手写笔势仍保持已锁定的 `time` 几何。
- “琴弦”效果只提供贝塞尔弧长纹理映射的研究方向；本效果使用独立 Canvas 2D 蒙版、母版和确定性时间逻辑。

## 验证记录

- `check_editor_contract.py` 通过；Edge/Playwright 控制台 0 错误。
- 实际检查写入中段、完整流动、擦除中段和纯底字，确认同向写入/擦除、冻结外轮廓与独立 `i` 点顺序。
- 修改底字为 `MOVE`、切换苹果五色，并依次切换 9:16、1:1，笔迹仍使用同一母版与时间轴，没有渲染器回退。
- 最终真实 PNG：640×360；最终真实 GIF：640×360、15 FPS、12 帧、0.80 秒。
- 最终真实 H.264 MP4：960×540、30 FPS、75 帧、2.500 秒完整循环；该文件同时替换画廊动态预览。
