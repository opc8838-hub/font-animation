# 流彩笔迹（Ribbon Ink）运动分析

## 证据范围

- 用户录屏：H.264，720×1556，30 FPS，273 帧；有效 16:9 内容区域为 720×405。
- 用户慢动作录屏 `飞书20260902-021322.qt`：H.264，540×1166，30 FPS，307 帧；有效内容区域为 540×304。逐帧检查了 4.00–10.00 秒的 180 帧。
- 正常速度决定循环节奏；10 FPS 与 30 FPS 密集切帧用于确认写入、纹理流动和擦除顺序。
- 手机播放器界面、悬浮辅助按钮和录屏留白不属于动效。

## 可见证据

| 时间段 | 观察 | 实现约束 |
| --- | --- | --- |
| 约 0.00–0.50 秒 | 彩色笔触从左下快速进入，在 `I` 附近骤然制动，随后再次加速向右完成；彩色点在写入末段独立弹入 | 使用单调但分段变速的弧长曲线，不用整体平移或透明度伪装 |
| 约 0.50–1.37 秒 | 外轮廓基本稳定，深紫纹理沿粉色笔触内部持续移动 | 轮廓与纹理分离；纹理由确定性时间驱动 |
| 约 1.37–1.94 秒 | 左侧先消失，右侧尾笔最后离场 | 擦除和写入同方向，使用同一弧长窗口 |
| 约 1.94–2.50 秒 | 笔迹清空，黑色 `I` 快速弹回，最后只剩完整 `TIME` | `I` 回弹由同一确定性时间轴驱动，无残影 |

## 慢动作锁定的接触事件

- 写入约 4.53 秒开始压低黑色 `I`，4.73 秒已压扁至不可见；这不是彩色层遮挡，因为 `T/M/E` 始终绘制在彩色笔迹之上。
- 彩色点约 5.33 秒独立出现，先位于稳定位置上方约半个点高，再下落并小幅回弹。
- 擦除约 8.20 秒开始抬升彩色点，8.43–8.47 秒到达最高处并消失。
- 黑色 `I` 约 8.60 秒开始恢复，8.73–9.03 秒完成带轻微过冲的弹回。
- 上述慢动作时间只用于判定动作顺序、轨迹和重叠；0.50/0.87/0.57/0.56 秒的正常速度节奏仍是最终播放基准。

## 冻结运动契约

- 黑色 `T/M/E` 始终存在；`I` 在笔迹接触时向下压缩并消失，擦除笔锋越过后弹性恢复。
- 彩色层是一个连贯的小写手写 `time` 笔势；`i` 点在写入末段独立出现，点内深紫纹理和主笔迹保持同一流动材质。
- 循环长度 2.50 秒：写入 0.50 秒、完整流动 0.87 秒、擦除 0.57 秒、底字停留 0.56 秒。
- 写入与擦除均从左向右；擦除不是反向回卷。
- 彩色外轮廓在完整阶段冻结，只有内部纹理运动；彩色点在入场和离场时独立纵向弹跳，完整阶段只保留细微弹性呼吸与内部色块流动。
- 预览、PNG、GIF 和 MP4 必须调用同一个 `renderFrame(time, width, height)`。

## 实现选择

- 使用一张 1672×941 的透明笔迹母版锁定完整外轮廓；母版只提供透明度，不包含底字、背景或时间帧。
- 贝塞尔中心线以累计弧长驱动写入和擦除蒙版；完整阶段直接显示冻结的母版轮廓，避免窄路径裁掉回环。
- 五色流纹沿同一中心线连续移动，并始终裁切在母版透明度内。文字、颜色、尺寸或导出变化不会切换另一套渲染器。
- 彩色点从母版独立分层，使用单独的延迟弹入、纵向落定、内部旋流与上挑离场。
- 黑色底字最后绘制；其中 `I` 使用接触压缩和离场回弹，其他字母保持原片的前后遮挡。编辑底字只改变文字层，手写笔势仍保持已锁定的 `time` 几何。
- “蛇形变速”把弧长进度拆成冲刺、制动、再冲刺三个单调区间；编辑器只暴露可解释的“蛇形顿挫”和“I 压弹”，不暴露内部贝塞尔系数。
- “琴弦”效果只提供贝塞尔弧长纹理映射的研究方向；本效果使用独立 Canvas 2D 蒙版、母版和确定性时间逻辑。

## 验证记录

- `check_editor_contract.py` 通过；Edge/Playwright 控制台 0 错误。
- 在确定性时间点 0.10、0.20、0.30、0.62、1.44、1.58、1.76、2.05 秒实际截图，并对最终 MP4 以 10 FPS 密集抽帧，确认蛇形变速、`I` 实体压缩/消失/回弹和彩色点上挑顺序。
- 根据正常速度复看，将 `I` 的实体下压扩展为约 0.18 秒、回弹扩展为约 0.24 秒；30 FPS 密集抽帧可连续读出“完整—压短—消失”和“底部短杆—向上过冲—落稳”，避免动作只剩闪现。
- 修改底字为 `MOVE`、切换苹果五色，并依次切换 9:16、1:1，笔迹仍使用同一母版与时间轴，没有渲染器回退。
- 最终真实 PNG：960×540；最终真实 GIF：960×540、30 FPS、75 帧、2.50 秒完整循环。
- 最终真实 H.264 MP4：960×540、30 FPS、75 帧、2.500 秒完整循环；该文件同时替换画廊动态预览。
