# 流彩笔迹（Ribbon Ink）运动分析

## 证据范围

- 用户录屏：H.264，720×1556，30 FPS，273 帧；有效 16:9 内容区域为 720×405。
- 正常速度决定循环节奏；10 FPS 与 30 FPS 密集切帧用于确认写入、纹理流动和擦除顺序。
- 手机播放器界面、悬浮辅助按钮和录屏留白不属于动效。

## 可见证据

| 时间段 | 观察 | 实现约束 |
| --- | --- | --- |
| 约 0.00–0.50 秒 | 彩色笔触从左下进入，沿同一手写轨迹向右完成；`i` 点在写入末段独立出现 | 保留逐帧写入次序，不用整体平移或透明度伪装 |
| 约 0.50–1.37 秒 | 外轮廓基本稳定，深紫纹理沿粉色笔触内部持续移动 | 轮廓与纹理分离；纹理由确定性时间驱动 |
| 约 1.37–1.94 秒 | 左侧先消失，右侧尾笔最后离场 | 擦除和写入同方向，使用同一弧长窗口 |
| 约 1.94–2.50 秒 | 只剩静态黑色 `TIME` | 无残影、缩放或透明尾巴 |

## 冻结运动契约

- 静态黑色大写底字始终存在。
- 彩色层是一个连贯的小写手写 `time` 笔势；`i` 点在写入末段独立出现，点内深紫纹理和主笔迹保持同一流动材质。
- 循环长度 2.50 秒：写入 0.50 秒、完整流动 0.87 秒、擦除 0.57 秒、底字停留 0.56 秒。
- 写入与擦除均从左向右；擦除不是反向回卷。
- 彩色外轮廓在完整阶段冻结，只有内部纹理运动；`i` 点位置不漂移，内部色块持续变化。
- 预览、PNG、GIF 和 MP4 必须调用同一个 `renderFrame(time, width, height)`。

## 实现选择

- 默认 `TIME` 使用从有效画面直接分离的 75 帧无背景图集，保留原始轮廓、内部深紫纹理和 `i` 点逐帧变化；黑字位于彩色层上方。
- 图集以 30 FPS、2.50 秒固定时间轴寻址；自定义阶段时长只重新映射相位进度，不建立第二套渲染几何。
- 用户修改文字、字形或笔迹颜色后切换到确定性的通用 Canvas 笔刷，避免固定图集忽略编辑器输入。
- 其他文字使用独立的通用彩色手势线，不把彩色文字副本硬叠在底字上。
- “琴弦”效果仅提供了曲线带状网格与弧长纹理映射的研究方向；本效果重新实现几何和时间逻辑，没有复制其 p5 源码。

## 验证记录

- 浏览器冻结检查：0.10、0.45、0.70、1.65、2.10 秒分别对应早期写入、`i` 点出现、完整、半擦除和纯底字；控制台 0 错误。
- 真实 PNG：720×406，1.65 秒擦除帧与同时间预览一致。
- 真实 GIF：720×406，30 FPS，75 帧；完整循环为 2.50 秒。
- 真实 H.264 MP4：720×406，30 FPS，75 帧，FFprobe 实测 2.500 秒。
- 已检查默认 16:9 图集渲染，以及 1:1 画布下的自定义文字通用笔刷回退。
- 已检查方案保存、导入、清理重做、恢复默认和自动保存。
