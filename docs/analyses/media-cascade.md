# 镜头铺展（Media Cascade）视频分析

- 参考：`排序7.qt`，约 4.13 秒，竖屏 540 × 1166。
- 核心编排：错位文字聚合 → 中央窄素材出现 → 横向复制成胶片 → 文字向两侧退场 → 胶片收拢为笔记本 → 屏幕放大至全画布。
- 原片只停在小笔记本镜头；根据需求增加“笔记本屏幕继续放大为全屏”的收尾。
- 媒体统一走同一个 `drawMedia` 裁切函数，图片、GIF 和视频共享胶片、笔记本与全屏三种空间状态。
- 上传视频导出时按目标帧时间主动 seek，避免 GIF/WEBM 导出的素材画面停在上传时的随机帧。
- 流畅性约束：单 Canvas、只使用 transform 等价的坐标插值、设备像素比上限 1.25、隐藏标签页停止绘制。

## 可编辑参数

八段独立时间、四种展开节奏、整体速度、复制数量/方向/间距、胶片宽高、笔记本大小与边框、全屏边距、素材播放速度、文字位置/字号/字距/光晕/退场距离，以及常用和自定义导出尺寸、时长、帧率。
