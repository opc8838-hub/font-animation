# 双页连续书写：纠正平移试验

## 本次运动契约（用户描述，不是新的视频重建）

- 冻结原单页、双页首页写入/流动、I/E/M 互动、母版和画廊预览。
- 废弃整张母版向右平移。已写笔迹固定在世界坐标里；只有笔锋弧长持续增长，沿新路线生成笔迹，尾部沿同一路线追随收回。
- 视角跟随跨页书写向右切换，不承担制造书写的作用；视角停止后笔锋依然沿曲线走，能回弯而不移动已经写下的点。
- 笔锋首次经过第二页中心时触发整字弹出，书写和弹出重叠；变速连续且无中途零速停顿。
- 第二页笔迹分段前后穿插。遮挡由当前字体的真实透明字形参与合成，不硬编码 M，也不画不透明矩形遮罩。文字缩放和遮挡使用同一个变换。
- 新路线先提供回环/绕行两种；配色继承原笔触角色，曲线光滑、压力缓变、内纹不规则，笔头/收尾圆润。本轮不是任意手绘路线编辑器。
- 第二页书写、收尾完成后保留原试验的文字停留与回首页循环；预览/所有导出共用几何和时间。

## 验收

固定世界点在镜头停稳后位置不变；改变时间只改变可见弧长。检查笔锋、接缝、前后穿插、任意字形和真实导出，并对原首页做像素回归。

## 当前边界

新曲线的材质是原有配色规律的程序化延续，不声称与原母版每个墨纹完全一致。穿插目前按曲线段交替，真实字形负责边缘遮挡；不是自动识别任意文字的最佳穿插点。自由手绘跨页和手动指定局部前后关系尚未加入。
