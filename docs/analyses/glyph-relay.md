# Effect analysis: Glyph Relay / 字标接力

## 2026-08-15 逐帧复核

- 新增原速参考 `113.qt`：1.90 秒、30fps、57 帧。第二段在 F26 硬切为黑色 `joy`；F28–30 为 y 的蓝/绿/红心跳，F30–32 为 o，F32–34 为 j，相邻字母重叠 1 帧，F35 已全部回黑。严格来说不是整词放大，而是颜色命中的单个字母以自身中心鼓起并回落。
- 原速参考中有效三段约为：第一段 0.55 秒、颜色接力 0.23–0.26 秒、第二段黑字停留约 0.20 秒、收尾切换约 0.27 秒、第三段停留约 0.30 秒。默认周期据此从慢动作的 5.20 秒恢复到约 1.60 秒，同时继续允许逐段拉长。
- 慢动作素材曾让整词尺寸变化显得明显；原速逐帧表进一步确认，真正的动感来自约 7 帧内 y → o → j 的单字颜色与局部缩放接力，整词外框应保持稳定。
- 第二段不再统一缩放整个单词；默认每个字母用 0.12 秒完成 100% → 118% → 100% 的独立心跳，颜色同步经历蓝 → 绿 → 红，相邻字母保留约一帧重叠。
- 原实现的调色板返回 `rgb(...)`，二次混色却只按十六进制解析，导致彩色值被错误当成黑色；现已兼容 RGB 颜色函数。
- 第二段仍使用一条确定性相位同步计算字母命中时间、局部缩放和颜色；提供 0.06–0.65 秒单字心跳时长、普通/峰值大小，以及柔和、快速、匀速和轻微回弹四种心跳曲线。
- 开头 F9–F25 的黑字包围盒中心从 264.5px 移到 286px，0.53 秒内累计右移约 21.5px；前半段每帧 0–1px，后半段提升到 2–4px，说明它是轻微加速右推而非静止停留。同时宽度只增加约 2%，因此默认采用二次以上 ease-in、22px 右移和 2% 轻微放大。
- 根据新需求移除彩虹轨迹。收尾改为复用纵跃的字位切换原理：原字位先衰减抖动，相邻字位平滑让位，选定图标再从 52% 弹至 100%；提供抖动、弹跳、直接切换三种方式，以及抖动强度和时长。
- 三段文案新增逗号分隔的逐字间距表。第 N 个数只控制第 N 个字位后的间距，正数拉开、负数收紧，所以文字与文字、文字与替换图标之间均可独立调整。
- 原速画面中第一段黑字高度约 72px，`joy` 黑字约 156–160px，收尾稳定文字约 76–77px；因此三段字号拆分为独立参数，默认第一段 122px、JOY 210px、收尾 122px，JOY 的单字心跳峰值再基于其独立字号计算。

## 复用

- 复用“图标爆发”的字体字位替换、颜色调色板与透明动物素材。
- 复用流墙的音乐、播放、云朵和手表图标风格。
- 预览和导出仍使用单 Canvas、确定性时间线和现有 GIF/WebM 编码模块。

## 编辑自由度

- 三段独立文案、字体、字重、字号、字距、画布锚点
- 第一段/换色/第二段停留/收尾切换/第三段停留分别调时，整体速度 0.25–4×
- 4 种颜色节奏、柔和度与 3 个颜色节点
- 第一段替换字位、第三段彩色字位、轮廓字位、图标槽宽/大小/偏移
- 项目内置图标、透明动物及用户上传图片/GIF
- 开头右移/轻微放大、收尾抖动方式/强度/时长；PNG、GIF、WebM 及主流尺寸导出
