## 代码对照
视频可读代码包含 SVG path、SourceAlpha、feGaussianBlur、feComposite、spreadMethod=repeat、animateTransform、feBlend overlay、feComponentTransfer 和 feTurbulence；现有 vendor/pro-svg-lab/renderer.js 使用相同原理。字形路径、色表和参数不据录屏宣称逐字节相同，保留 Johnlzx / Mike Bespalov / Refero 署名。

## 运动合同（用户纠正后锁定）
- 原有默认方案、图库视频、字形、滤镜、扫描周期和首次柔和揭示保留；新增模式默认关闭。
- 原材质动画先完整播放，之后追加：放大 → 文案出现/逐字 → 文案停留 → 文案淡出 → 缩回 → 原构图停留 → 可选空隙。
- 字形与图标作为同一组绕画布中心缩放，scale 从 1 到设置倍数再回到严格的 1；放大和缩回使用 smoothstep，端点速度为零。文案固定屏幕坐标，缩回前消失。
- 材质始终用原扫描周期、色谱方向及滤镜，不再以文案时长重设扫描周期或强制关闭首次揭示。原段落停留留在正常构图阶段；扫描与揭示控件保持可编辑。
- 呼吸只作用于放大后的文案阶段，两端为零，不妨碍恢复原构图。
- 总速度缩放全部阶段；PNG/GIF/MP4 共用确定时间 renderer，输出按实际画布尺寸。
