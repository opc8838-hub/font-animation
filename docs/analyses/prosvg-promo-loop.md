## 目标
放大的彩色 SVG 字形作为流动底层，上方独立编辑宣发文案；可调文字出现、停留、淡出、空隙和整轮速度，预览与导出一致。

## 代码对照
视频可读代码包含 SVG path、SourceAlpha、feGaussianBlur、feComposite、spreadMethod=repeat、animateTransform、feBlend overlay、feComponentTransfer 和 feTurbulence；现有 vendor/pro-svg-lab/renderer.js 使用相同原理。字形路径、色表和参数不据录屏宣称逐字节相同，保留 Johnlzx / Mike Bespalov / Refero 署名。

## 运动合同
- 原有默认方案、图库视频、字形和材质不改；新增模式默认关闭。
- 底层字形、图标作为同一放大组，在画布中心变换，可有周期性呼吸缩放。
- 前层文案保持屏幕坐标，不随底层缩放。默认完整文本柔和出现；逐字出现为用户可选扩展。
- 每轮：出现 → 停留 → 淡出 → 空隙。每段原有停留时间加到文案停留阶段。总速度缩放全部阶段。
- 色谱每轮运行整数个周期，缩放曲线在边界位置和速度一致，避免循环闪断。
- 所有阶段由确定时间决定，PNG/GIF/MP4 共用 renderer，输出按实际画布尺寸。

## 可调参数
模式开关、放大倍数、呼吸幅度、叠加文案、共享字体、字号、颜色、垂直位置、逐字开关、出现时间、停留时间、淡出时间、轮间空隙、每轮色谱次数、总速度。

## 不确定项
- 原视频完整最终代码受分辨率限制不可逐行可靠转录。
- 开头放大没有可证实的独立缩放运动；呼吸缩放和逐字是本次新增能力，不声称视频原有。
- 不制作教学代码打字展示或复制手机平台外壳，用户目标是可编辑宣发构图。
