# Ribbon Ink 自由绘画

## 范围与冻结项

- 保留 TIME 母图、画廊预览、I 压弹、彩色点、写入/流动/擦除/留白的原有实现和默认值。
- 自由绘画只替换内容几何：按鼠标落笔顺序记录多笔画；不生成文字弹跳。
- 原始路线和笔压保存在方案中；粗细滑块乘以同一局部宽度曲线，不重写路线。
- 预览和 PNG/GIF/MP4 都经 `renderFrame`，同一弧长窗口决定写入与擦除。

## 2026-09-04 视觉修正契约

用户指出第一版“等粗圆管 + 平行细条 + 五色线性渐变”不符合已做好的 TIME。
本次对照 `ribbonink-brush-mother.png` 和原版 `drawMainBrush`，锁定以下材质角色：

- 颜色 1 是主要笔触底色，颜色 2 是不规则深色纹路；不是均匀的彩虹渐变。
- 一条宽窄、位置不规则的深色纹路在底色中游走，局部越过轮廓后被裁切，形成不连续色块；辅以稀疏浅色墨池。
- 外轮廓有落笔/收笔、笔压和沿路径的缓慢粗细起伏；鼠标快划偏细、慢划偏厚。旧二维坐标方案仍可加载。
- 外轮廓不随播放时间抖动；只允许内部纹路流动。随机形状由固定种子决定，刷新与导出不重新抽签。
- 急弯与交叠处以不透明圆头笔触叠合构建轮廓；内部色层使用与 TIME 相同的 alpha 蒙版思路，避免偏移轮廓自交产生白色裂缝。

本轮不重新分析或修改原视频节奏，也不修改已批准的 TIME 预览资产。

## 最终打磨与验证

- 用户指出粗糙版本有随机鼓包；已把外轮廓噪声降为低幅、长尺度变化，笔压经过空间平滑，落笔/收笔逐渐过渡。路线本身不加随机抖动。
- 内部墨纹采用曲率连续的三次 B 样条变化，移除短周期折返与密集墨点，保留长墨流和稀疏尖收色块。
- 五色按主色、内部墨纹、浅色点缀、两种流动辅色编辑；预设与自定义色均可保存。改色和调整粗细前后，序列化路线/笔压逐项一致。
- 普通刷新恢复自动保存；画廊入口与恢复默认使用不可变的 TIME 默认值。旧 XY 点与新 XY+笔压方案均可导入。
- 实际鼠标补画一笔，检查笔压记录；撤销/重做、方案 JSON 下载/导入、恢复默认、刷新恢复、四组预设、面板/舞台播放同步通过。
- 16:9、1:1、9:16 舞台比例检查通过；390×844 手机视口画布位于编辑器上方，编辑区独立滚动。
- 实际导出：960×540 PNG、H.264 MP4（30 FPS、75 帧、2.500 秒），540×540 GIF（75 帧）。提取真实导出的写入、完整流动、擦除和留白帧目检。
- 相同逻辑尺寸/时间下预览与离屏输出共用渲染器；缩放采样造成的平均通道差为 0.0033/255，不存在独立几何或时间轴。
- 当前手绘测试案例在 540×540 完整流动段平均渲染约 2.2 ms/帧（20 次采样）；轮廓缓存不包含时间相关纹路。
- 浏览器 0 错误；共享 GIF 编码器有一条 Canvas 频繁读回性能提示。静态编辑器契约、Node 笔压/采样回归、语法与 diff 检查通过。
- 对比开发前版本：TIME 的 I 压弹、彩色点、绘制、蛇形节奏函数逐项未改；母图及画廊 MP4 字节未改。

视觉匹配以用户下一次检查为准；本记录不宣称任意手绘已达到原视频的逐像素复刻。
