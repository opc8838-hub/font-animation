# 第二页路线选项

## 本轮契约

- 在既有回环、弧线之外新增横向波浪、八字回旋、螺旋展开。属于创作扩展，不是原片新增观察。
- 冻结首页、已有两条路线、材质、配色过渡、弧长头尾时钟、文字接触动作与退场。仅增添贝塞尔路径及选择入口。
- 每条路线从原有跨页连接笔段出发，经过中心触发整字弹出；后续连接保持切线连续，最终右侧出画。不能重新显现整条轨迹，也不能以整体平移代替书写。
- 现有页面配色、快慢节奏、穿插选择与逐字标注继续作用于新路线；保存/导入仍使用稳定的 page2Route 值。
- 添加“播放这条笔迹”，从跨页前少量时间开始播放，方便观察不同路线全程；选择路线依旧暂停于第二页关键帧。

## 验证

- 原有 loop / arc 几何序列 SHA-256 与改动前完全相同；新三路在 16:9、1:1、9:16 下取样有限、连接位置连续、接头切向差小于 0.06 rad，快慢设置下头尾均单调推进并完全退出。
- 七项 Ribbon Ink 回归、编辑器结构、JS 语法及 diff 空白检查通过。
- 浏览器逐一切换、点击“播放这条笔迹”；每条实际下载 960×540、30fps、103 帧 MP4，并按 12fps 提取续写至收笔的密集帧检查。另检查螺旋实际 GIF。
- 三条路线实际 PNG；八字中文方形、螺旋日文竖版、波浪韩文竖版输出检查通过，英文在三条横版视频中检查。390px 手机视口无横向溢出，路线选择/播放均可见。
- 八字的前/后/交错产生三种不同合成结果；独立蓝色预设可用，首页内容/颜色与总时长不变。JSON 下载、刷新恢复、导入均保留 eight；恢复默认仍为 loop。
- 本轮只增加路线与 UI 入口，不改材质、已有节奏、字体反应、导出实现或画廊资产。浏览器无错误；GIF 库既有 Canvas readback 性能提示未扩大处理范围。
