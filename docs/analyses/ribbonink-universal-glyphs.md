# 两页通用字形与快速退场

## 本次运动契约

- 两页文字退场统一调用 `singleTextExit`：整组围绕实际字形底边持续下压至零高度，无横移、回弹或中途停顿。两页默认时长均为 0.20 秒，可分别编辑。覆盖此前第二页右移退场和单页 0.34 秒默认值。
- 原版 TIME + Roboto Condensed 的自动编排保留 I/E 和 M 的既有细节。换文字、换字体时使用通用字形系统；第一页修改逐字设置会进入“逐字自定义”。
- 两页各自保存字素 ID、穿插层次、接触动作、幅度、方向、支点和回弹时长。插字通过字素匹配保留原字设置；换字体不丢标注。
- 支持整字自动轻压、不动、下压回弹、压下隐藏、侧让和轻转。处理整字变形，不自动拆解汉字、假名或任意字体内部笔画。实际未与路线相交的字不强行触发。
- 首页触发由实际字体 alpha 和已批准笔迹路线的采样位置求交，释放由同一擦除时间轴求逆；两页模式的首页在移出镜头时释放。前后交错使用随路径分段的遮罩，显式前/后标注覆盖自动遮罩。
- 第二页不再只检测笔尖，同时检测文字弹出时仍可见的笔迹主体，解决更换字形后漏触发的问题。接触计算只在布局/路径/节奏改变后重建，渲染复用缓存字形。
- 两页共用字形渲染器，预览/PNG/GIF/MP4 共用 `renderFrame`；字体载入后重新测量，按实际字形底边定位支点。

## 验证记录

- Inter 英文、Noto Sans SC 中文、JP 日文、KR 韩文，分别验证两页短/长文字的非空接触事件和实际形变。四种字体均生成 1080×1080 PNG。
- 逐字 UI 设置第一页“中”为隐藏/笔迹在前，第二页“あ”为轻转/笔迹在后；第一页插入 X 后设置仍归原字。刷新、方案导出/导入均保留两页独立标注。清理重做清空两页标注；恢复默认恢复 TIME 及两页 0.20 秒退场。
- 前后层切换像素比较：400×400 下第一页 9515 像素、第二页 3579 像素发生变化，确认控件接入实际合成。
- 两页中文实际导出 MP4/GIF：960×540、30fps、102 帧，视频 3.40 秒，对应确定性时间轴 3.38 秒。检查整段及退场密集帧。
- 第二页下压采样底边固定 y=148，上边由 y=76 连续下降至 y=137，结束时无文字像素。
- 前台播放采样：帧间隔中位数 16.7ms、P95 33.4ms；后台页存在浏览器限帧，不能用后台采样判断动效卡顿。
- glyphs、single-ending、motion、sequence 定向脚本、编辑器结构、语法与差异检查通过。GIF 编码保留既有 Canvas readback 性能提示，无浏览器错误。
