# 视频对比 / Video Compare

## Source material

- 参考：用户本机「对比/参考.jpg」，以及同目录两份 B2W / Back 2 Work Studio 黑白 Logo。
- 分析日期：2026-10-12。
- 参考为静态截图，没有参考视频或可观察的动作时序。按用户要求不增加动效；源视频各自播放。
- 截图里的工作流、模型及其它说明不进入成品；底部仅保留 B2W Logo。

## One-sentence target

将「网上看到的 / Before」和「我做的 / After」两段视频放进同一张干净的对比画面，可编辑、同步预览并导出。

## Element model and spatial rules

- 默认 1920 × 1080，两个等宽 16:9 视频框左右并排；标题与说明在框上方，B2W Logo 居中在底部。
- 16:9、4:3、3:2、1:1 及横屏/方形自定义偶数尺寸。方形用上下排列的两个 16:9 框。
- **9:16 成品版式未实现，选项禁用**。用户要求后续单独排版；导入/自定义尺寸也拒绝竖屏输出。
- 横屏、竖屏和方形源视频均可使用。默认完整显示，可切换铺满裁切，并独立缩放和调整水平/垂直取景。
- 画布按实际 stage 客户区居中适配。预览 CSS 只缩放，逻辑像素和导出尺寸一致。
- 任意中英文标签，可用完整共享字体库。UI 语言/深浅色与成品黑白配色独立。

## Timing and reuse

- 完整视频时长取两段已裁剪片段的较长者；可选 3/5/10 秒或自定义 0.1–120 秒。无素材的模板预览为 6 秒。
- 无入场、转场、缓动或退出编排。时间轴使用真实双视频播放及末帧保留/循环阶段，颜色为蓝与紫。
- 沿用 Type Cascade 三栏、方案四按钮、播放/重播、时间轴、共享字体与中英文/主题层。
- 固定两个视频槽位，不引入与当前用途无关的图标库、文本段落增删、工作流或 AI 组件面板。
- 原有 beforeafter 图片动效不受影响；新入口为 video-compare.html。
- PNG / GIF / MP4 共用 renderFrame、geometry 和 sourceTime。视频帧等待解码及 seeked，不使用实时录屏。
- H.264 MP4 用项目现有 HME 编码器，24/30/60 fps；GIF 至多 30 fps；PNG 保存当前暂停帧。

## Editing and persistence

- 两段素材独立上传、替换、移除、裁剪，缩略时间轴可拖拽或方向键微调。
- IndexedDB 自动保存完整方案和嵌入视频；下载 JSON 可迁移，导入恢复全部媒体和参数。
- 保存、导入、恢复默认、清理及 Ctrl/Cmd+Z / Shift+Z / Y 撤销重做。
- 每段上传上限 200 MB，使用浏览器可解码的视频（MP4/WebM/MOV 容器内编码须浏览器支持）。
- 当前视频导出**无声**，编辑器明确显示。参考与需求未指定音轨混合策略。

## Uncertainties / deferred scope

- 原截图为竖屏；当前横屏重排为本轮实现方案，仍待用户视觉确认。
- 9:16 成品重新排版按用户指示延期。
- 音频混合/保留未定义，本轮导出无声音轨。
- Logo 为用户提供素材，仅裁出原有标志并处理透明度，没有重画或重新设计。

## Acceptance evidence

2026-10-12，在 Windows 上使用 Node Playwright + 安装的 Microsoft Edge 执行 tests/video-compare-browser.cjs，全部通过：

- 三栏壳、两固定槽位、四个方案操作。
- 320 × 180 横屏与 180 × 320 竖屏真实 MP4 上传、同步总时长、独立裁剪及精确定位。
- 中文输入、黑白成品、界面语言/主题切换保持编辑内容。
- Manrope、Noto Sans SC Black、Noto Sans JP Black、Noto Sans KR Black 四个共享字体的中英日韩标签均预览并实际导出 PNG。
- 自动保存刷新恢复、包含两段视频的 JSON 保存/清理/导入。
- 自定义 640 × 360，先改宽再改高不会被旧高度覆盖。
- 实际生成 PNG 640 × 360，与当前暂停画布像素完全一致。
- 实际生成 H.264 MP4 640 × 360；0.4 秒 × 24 fps 上取整为 10 帧，解码时长 10/24 秒。
- 实际生成 GIF 640 × 360、10 帧；实际生成 1080 × 1080 方形 PNG。
- 1440/1200/1024/768/390 像素视口无横向溢出，方形画布在 stage 内；手机 stage 优先。
- 浏览器无运行错误；9:16 输出入口禁用。
- 已核对桌面左右栏内部滚动，上传/裁剪/版式/导出操作可达。

测试导出及截图位于被忽略的 output/video-compare/，不提交私有参考素材或测试源视频。新增静态封面与目录入口纳入本次代码；本轮仅本地制作，未发布网站。
