## 第六轮可选展示背景

- 画布工具栏新增“铺满背景 / Fill backdrop”开关，默认关闭且不写入作品方案。
- 开启后，舞台留白跟随当前选中段落的背景颜色，隐藏构图框阴影，使录屏画面形成连续背景；切换段落或修改单段/全局背景色时实时同步。
- 该模式只改变编辑器舞台的 CSS 背景和构图框阴影，不修改画布尺寸、字体/图标参数、预览渲染器或导出内容。

## 本次结构

- 顶部：CellMotion 原图 Logo、字倾名称、返回新组件库、导出入口。
- 左侧：紧凑段落导航、添加段落、方案保存/导入/恢复/清理。
- 中间：画布比例选择、等比缩放的真实画布、播放控制与原有时间轴。
- 右侧：当前段落 / 全局设置 / 导出。仅显示选中段落，图标库占用同一右栏。
- 桌面控件正文以 14px 为基准，段落文本输入 17px；移动端画布在上，段落横向选择，属性在下。

## 实现边界

`typecascade-workspace.js` 移动原控件，不复制编辑状态；原行 ID、字体库、背景上传、图标编辑、方案格式和渲染导出函数继续沿用。
文字和停留修改后定位并暂停在当前行，倾倒时长修改仍沿用原来的自动预览。
CSS 仅作用于字倾的 `tc-workspace`。`?preview` 卡片预览不应用该布局。
本次不修改动画编排、默认示例或其他动效。用户确认后，共享 Skill 已将本编辑器的结构、视觉、主题、语言、段落工具、时间轴和导出规则提升为 CellMotion 标准；具体动效设置仍按各动效能力保留。
