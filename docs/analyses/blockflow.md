# 方块流动：Bot 语音原段独立成片

来源：仓内 `site/botvoice-native.js` 的亮蓝方块流动段，对应第三段参考视频 2.85–6.05 秒。独立时间直接映射这 3.20 秒；正常速度决定节奏，原视频慢放只用于确认块的分合顺序。

| 独立时间 | 观察到的形态与运动 | 阶段 |
| --- | --- | --- |
| 0–1.35 s | 中央先是一块完整亮蓝方块，再横向展开为八块；宽度由约 103 px 增至约 977 px | 方块展开 |
| 1.35–2.65 s | 八块高度沿原段的关键形态连续变化；蓝色纹理和光团沿整个横带运动 | 方块流动 |
| 2.65–3.20 s | 横带收拢、外侧块淡出，末尾收成蓝色圆点 | 收拢归一 |

几何采用 1080×1920 原生坐标。宽度、高度、PCHIP 高度轮廓、分块间距、边缘收拢和流体纹理均来自 Bot 语音的现有实现。首帧额外使用一个连续的圆角方块轮廓，避免默认八个重叠分片出现白色竖缝。默认图标可见度为 0；用户可以打开图标叠加、替换图片或图标，也可以新增方块。新增数量通过对原有八块轮廓采样扩展，仍使用共享素材模型。颜色、尺寸、起伏、速度、间距、圆角和阶段时长可调整。

冻结范围：Bot 语音的手机、飞行和语音阶段不改；原段八块的默认时间与纹理不改。

不确定处：原片只展示八块，新增数量的轮廓插值属于编辑器扩展，并不声称来自原片。

验证：独立段与 Bot 语音相同时刻 1080×1920 画面平均通道差 0.27；首帧只有一个连续方块；新增第九块与图标可见度会影响渲染；中文、响应式布局、For AI、PNG/GIF/MP4 已实际检查。
