# 第二页流动墨纹与跟随文字退场

## 本轮契约

- 冻结首页、第二页外轮廓、路线、头尾时钟、前后遮挡和接触回弹。仅重做内部辅色轮廓与材质流速。
- 用户否定圆头胶囊式辅色。改为粉紫两大色域互相侵入的二维墨纹场，软合并/软减去形成鼓包、圆滑分叉和收腰；闭合等值线用二次曲线平滑，避免尖角与小条贴片。纹理在路径内部持续流动，慢写期间不能静止；流速 0 为用户显式冻结。
- 用户补充覆盖上一版“结束留下文字”：笔迹完全收走并完成接触回弹 → 文字停留 → 整字轻带向右、弹性收缩并消失 → 留白。
- 文字停留、文字消失时长、结束留白可编辑；变化同步于预览、PNG、GIF、MP4 与时间线。没有笔迹和文字同时闪灭。
- 第二页默认沿用首页配色；可选独立五色/预设、复制首页配色。独立颜色随跨页连接笔段逐步带入，到达文字前完成；后续回环保持第二页颜色，不因回到画面左侧而返色。同色路径直接使用原色，不引入额外渐变。

## 本轮参考证据

- 实际重新观看桌面 `飞书20260902-021322.qt`（540×1166、30 fps、约 10.26 秒）；Watch 1 fps 顺序全览，FFmpeg 对 5.4–7.4 秒有效画面密集提取 10 fps。
- 正常速度 `飞书20260901-005314.qt` 当前不在桌面，本轮未声称重新观看。慢片只用于色块形状/流动顺序，不推导原速节奏。
- 原片主次色域宽度不等，紫色常贴到外缘，粉色侵入形成圆滑凹口。存在少量小岛，但不呈均匀胶囊排列；因此否定“只给短条加圆头”和“仅一条平滑波纹”两版中间尝试。
- 色域缓存位于材质弧长空间，逐帧只平移材质坐标并弯曲到现有路线。按笔段裁切，防止另一回环的纹理投影生成尖碎片；色块不参与前后遮罩。
- 墨纹边界额外按笔宽 9% 做圆连接描边扩张，给狭窄分离端保留有限半径，不能仅靠样条“看起来光滑”。
