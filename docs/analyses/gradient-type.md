- 文字使用一条确定性时间线，只改变可见字符数量，不创建逐字 DOM 节点。

- 背景由单个 Canvas 线性渐变绘制；颜色节点按连续相位采样，文字停留时背景仍运动。
- 预览 DPR 上限 1.25；页面隐藏时停止 RAF；暂停时只在参数变化后重绘。
