# LTMorphingLabel 四种字形动效移植分析

日期：2026-09-02

参考实现：<https://github.com/lexrus/LTMorphingLabel>（MIT）。本项目只移植可观察到的逐字运动合同与数学参数，使用现有 Canvas、编辑器、图标库和确定性导出栈重新实现，不嵌入 Swift/UIKit 源码。

## 独立产品命名

| 上游实现标识 | 本项目名称 | slug | 默认演示词组 |
| --- | --- | --- | --- |
| 默认缩放实现 | 字芽 Sprout Shift | `sproutshift` | SPROUT → 留白复位 |
| 上升消散实现 | 雾升 Mist Lift | `mistlift` | MIST → 留白复位 |
| 倾倒坠落实现 | 字倾 Type Cascade | `typecascade` | CASCADE → 留白复位 |
| 低分辨率像素实现 | 点解 Dot Resolve | `dotresolve` | RESOLVE → 留白复位 |

四页没有动效模式切换器；共享代码只负责一致的编辑、图标、时间轴和导出能力。默认方案各自只有一个可见演示名称，第二行是不可见的循环复位状态；由“名称出现—稳定停留—名称退出—留白复位”构成单一节奏，避免多个词连续变化掩盖效果差异。用户仍可主动扩展为多词序列。

## 共同运动合同

- 默认单次变形时长为 600ms，字符错峰为归一化进度 `0.026`。
- 旧字符按从左到右的贪心匹配寻找新字符串中尚未占用的相同字符。
- 匹配字符只沿基线从旧字位移动到新字位，位移使用 `easeOutQuint`。
- 未匹配旧字符执行退出，未匹配新字符执行进入；相同字符不重复绘制。
- 正常速度决定最终节奏；官方 GIF 的逐帧画面用于确认上下方向、旋转枢轴和像素块变化。
- 图标作为行内 token 参与同一匹配和运动，但仍保留独立大小、字图间距、水平和垂直偏移。

`easeOutQuint(p) = 1 - (1 - clamp(p))^5`；`easeInQuint(p) = clamp(p)^5`。

## 分页相位表

### 字芽 Sprout Shift

| 相位 | 进度 | 可观察行为 |
| --- | --- | --- |
| 稳定停留 | 行停留时长 | 当前整行完整、清晰、居中 |
| 旧字退出 | `p + delay × oldIndex` | 未匹配字符围绕基线快速缩小并淡出 |
| 字位迁移 | 同上 | 匹配字符以五次缓出横移到新字位 |
| 新字进入 | `p - delay × newIndex` | 未匹配字符从近零尺寸长大并以全局进度淡入 |

### 雾升 Mist Lift

| 相位 | 进度 | 可观察行为 |
| --- | --- | --- |
| 稳定停留 | 行停留时长 | 当前整行完整可读 |
| 旧字升散 | `p + delay × round(cos(i) × 1.2)` | 上移 `0.8em` 并淡出，逐字错落 |
| 字位迁移 | 同上 | 匹配字符沿基线五次缓出 |
| 新字浮入 | `p - delay × round(cos(i) × 1.2)` | 从基线下方 `1.2em` 上升，使用全局透明度淡入 |

### 字倾 Type Cascade

| 相位 | 进度 | 可观察行为 |
| --- | --- | --- |
| 稳定停留 | 行停留时长 | 当前整行完整可读 |
| 失衡倾倒 | `p + delay × sin(i) × 1.7` | 旧字围绕近底部枢轴向左右交错旋转，角度方向由字位决定 |
| 后段下坠 | 倾倒进度大于 0.5 | 枢轴额外下移约 10pt，并在后半段快速淡出 |
| 新字长入 | `p - delay × i / 1.7` | 新字围绕基线由近零尺寸长到完整尺寸 |

倾倒使用上游 `easeOutBack` 的 `s = 2.70158`，默认最大角度为 168°。

### 点解 Dot Resolve

| 相位 | 进度 | 可观察行为 |
| --- | --- | --- |
| 稳定停留 | 行停留时长 | 当前整行完整可读 |
| 旧字颗粒化 | 默认旧字错峰 | 字符先低分辨率栅格化，再以最近邻放大，后半程淡出 |
| 字位迁移 | 默认旧字错峰 | 匹配字符仍保持清晰并沿基线迁移 |
| 新字解析 | 默认新字错峰 | 从最粗像素块逐步恢复清晰，同时淡入 |

像素采样比例为 `min(deviceScale, 1 / (progress × 6))` 的 Canvas 等价实现；零进度直接绘制清晰字形。

## 已冻结与不确定项

已冻结：上下方向、五次缓出、600ms 默认时长、0.026 字符错峰、雾升的 0.8/1.2em 位移、字倾的近底部枢轴/168°/后段淡出、点解的 6 倍像素半径。

不确定项：UIKit 字体度量与浏览器字体栅格化不同，Canvas 只能保持视觉等价的基线与字框；上游 GIF 的展示停留时间来自示例应用，不属于四个效果实现，因此本项目把行停留作为可编辑时间轴参数。
