# 第二页逐字穿插与笔锋接触动作

## 运动和编辑契约

- 原首页 I/E/M、跨页书写几何、笔迹材质和画廊母版冻结。新增功能只属于第二页。
- 按 Unicode 字素选择一个或多个字，设置默认穿插/笔迹在前/笔迹在后；动作独立于穿插，可选自动轻压、不动、下压回弹、压下隐藏、侧让和轻转。
- 方向、支点、幅度与回弹时长保存在对应字素上；插入和删除文字通过最长公共子序列保留未变文字的标注，不用数组下标把动作错给邻字。
- 固定设计坐标的真实字形 alpha 与笔锋圆头接触，得到开始时间与路径弧长；笔尾离开接触区后释放。整字入场达到可读阶段后才触发局部动作，避免两套缩放竞争。
- 回弹轻微过冲后落稳，不在每帧积累物理状态。任意跳帧、倒放采样、PNG/GIF/MP4 均使用同一纯时间状态。
- 只变形整个字，不宣称自动拆分汉字内部笔画。没有笔锋接触的字保持不动；可以用暂停接触与局部播放检查原因。
- 默认轻压遵从前后关系：从后面穿过时弱响应。手工指定的动作由用户决定，不暗中绑定穿插选项。

## 首尾圆润度修订（2026-09-05）

- 对照桌面 `20260905-003929.jpg` 红圈和原笔迹母版，问题是笔尾收至局部笔身的 28%、笔头收至 68%，形成细颈接小圆头，而非整条笔迹不够粗。
- 改为尾部 94%、头部 96% 的饱满半圆收口，沿原 46/32 设计单位的平滑区接回笔身。中段有机粗细、路线、内部配色与运动时序不变。
- 绘制、前后遮挡蒙版与字形接触共用同一半径函数；粗细编辑与导出同步生效。没有修改原首页母版。

## 实际验证

- 四项定向脚本通过：原 I/E/M、自由绘画、连续路线、逐字标注/动作/圆头；JS 语法和共享编辑器契约通过。
- 浏览器实测单字前后切换仅改变该字覆盖区；多选混合值、插删字保留标注、方案保存再导入完全一致。
- 普通刷新恢复、旧 v6 方案默认迁移、清理重做为空、恢复默认均通过。
- FLOW 与“你好あい”实测接触、下压、隐藏、回弹；隐藏中无残留黑条，未接触的字不强行动作。中日文字体加载检测包含实际文字，避免只检测拉丁字符。
- 1440×900、390×844 编辑器没有横向溢出；实际导出 1920×1080、960×540 横屏 PNG 和 1080×1920 竖屏 PNG。
- 真实 GIF/MP4 均为 960×540、114 帧、3.8 秒；MP4 为 H.264 / 30 FPS。2.1 秒帧与 PNG 的 RGB 平均误差分别为 GIF 0.332/255、MP4 2.028/255，符合编码与调色板差异。
- 检视 1.95、2.03、2.10、2.14、2.17、2.22 秒首尾形态，以及实际 MP4 中隐藏保持、释放、回弹和落稳帧。
- 任意跳帧后同时间重新渲染像素完全一致；单页/双页的首页七个采样时刻完全一致。
- 实时播放五秒采样中位帧间隔 16.7ms、P95 33.5ms、最大 66.6ms；已预热字体与接触缓存，仍有偶发掉帧，不宣称稳定 60 FPS。
- 浏览器无 JS 错误。GIF 共享编码器提示一次 Canvas readback 性能建议，不影响生成。
- 本次证据位于 `output/playwright/glyph-reactions/`，不提交输出缓存。
