# 单页结尾编辑

## 契约

- 单页与两页继续由“播放结构”选择，不强制新增第二页。
- 单页原版文字模式的结尾为：笔迹擦除 → 文字停留 → 整字围绕实际字形底边持续向下压至零高度并消失 → 留白。宽度不变，无回弹、横移或中途停顿，最后 35% 同步淡出。
- “擦除”“笔迹消失后，文字停留”“文字消失时长”“结束留白”分别控制上述四段，并共同驱动时间线、预览、PNG、GIF、MP4。
- 单页文字退场使用独立的 `singleTextExit` 几何，围绕单页文字实际位置变换；两页继续冻结原有 `textExit`，二者仍共用同一导出渲染器。
- 自由绘画没有底字，保持原有写入、流动、擦除、留白四段；隐藏无意义的文字退场控件，原有总时长不变。
- 冻结首页写入、I/E 动作、母图、配色流动、两页全部阶段、第二页路线及穿插。

## 验证记录

- 默认单页总时长为 `3.04s`：写入 `0.50s`、流动 `0.87s`、擦除 `0.57s`、文字停留 `0.56s`、文字退场 `0.34s`、结束留白 `0.20s`。退场使用全程单调的连续缓动，无中间反向阶段；预览和导出均按实际字形底边定位支点。
- 两页模式仍为 `3.42s`，自由绘画仍为 `2.50s`；二者都不会显示单页文字退场控件。
- 浏览器验证了方形中文与竖屏日文；退场相位、画布尺寸和文字组合层均正确，整字不会因前后穿插层重复叠加而深浅不一。
- 单页尾段参数可自动保存、刷新恢复、导出方案并重新导入；恢复默认与清理重做保留字段合法值。
- 本次直接下压版本实际生成了 1920×1080 PNG、30fps MP4 与 GIF，并检查导出尾段连续帧；中文方形画布采样中底边固定在 y=265，上边由 y=131 连续下降至 y=252，最终无文字像素。
- 本次语法、差异、single-ending 与 sequence 定向检查通过。浏览器无错误；GIF 编码存在原有 Canvas readback 性能提示。
