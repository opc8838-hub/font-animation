# 第二页独立节奏与短收笔

## 运动契约

- 依据本轮用户批准的设计，不改变原视频复刻首页、路径、圆头、颜色或字形穿插规则；无新参考视频。
- 第二页使用独立单调弧长时钟：总书写时长、匀速/快慢快、慢动作位置/长度/力度。慢区仍持续书写，不能冻结或反向。
- 书写阶段推进到原路径的 84%，随后默认 0.36 秒收笔：头部短顿后加速出右边，尾部沿同一路径追赶。不是整体平移、缩小或透明擦除。
- 首尾沿连续路径推进；末尾越过画布（包含圆头半径）后完全消失。最后触及的字由同一笔尾时钟释放并快速落稳，不额外强迫全字跳动。
- 收笔结束保留完整文字。成片不再淡化回首页；预览循环是在最终文字停留之后重新开始。
- 所有编辑、任意跳帧与 PNG/GIF/MP4 共用时钟和几何。首页参数不控制第二页速度。

## 验证

- 新增定向测试覆盖两条路线、0.55/0.9/1.6 秒书写、三种节奏、慢区位置与长度边界；首尾单调、交界位置连续、尾不越头、收笔完全退出、逐字释放与笔尾同钟均通过。
- 原运动、手绘、连续书写、逐字反应四项回归，以及 JS 语法和编辑器契约通过。
- 浏览器实测第二页参数修改不改变首页 0.7 秒的像素；清晰匀速禁用慢区设置；收笔时长从 0.36 调到 0.50 秒，完整时长精确增加 0.14 秒。
- 保存再导入、普通刷新恢复逐项一致；清理重做和恢复默认通过。全新选项随方案 v8 保存，旧方案缺省载入新的独立节奏默认值。
- 实际导出 960×540 PNG/GIF/MP4。默认模型 3.88 秒，GIF 117 帧 / 3.88 秒；H.264 为 30 FPS / 117 帧 / 3.90 秒（末帧量化，不改变采样时刻）。
- 视频第 72 帧（2.4 秒）与 PNG 同帧比对，RGB 平均误差 MP4 1.867/255、GIF 0.831/255；同一时刻乱序重新渲染像素完全一致。
- 检查真实 MP4 2.20–2.77 秒的连续 30 FPS 帧：沿原路线收笔、受影响的字依次释放、结尾无笔迹残留。2.8 与 3.86 秒的最终文字完全一致，无淡回首页。
- 中文、日文、韩文真实 PNG 可读；16:9、9:16、1:1 尺寸切换，实际 1080×1920 PNG 导出；1440×900 桌面和 390×844 窄屏检查通过，无横向溢出。
- 当前页面无 JS 错误；GIF 编码时共享库仅有 Canvas readback 性能建议。证据在 `output/playwright/ribbon-ending/`，不提交缓存。
- 首页、母版图片、批准的画廊预览和其他动效均未修改。
