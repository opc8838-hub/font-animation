## 本地检查

通过静态 HTTP 服务打开 site 目录。运行 node scripts/preview-archive-motion.cjs 即可启动预览；当前检查服务为 http://127.0.0.1:8768，页面分别是 botvoice.html、patentwall.html、animalwave.html。动画库和全局导航均已加入入口，总数 78（46 已就绪，32 待制作）。画廊入口带 from=gallery，始终打开随附默认方案；直接打开或刷新编辑页会恢复本浏览器的自动保存内容。

三个页面共用 cardmotion-editor.js、字体库、图标库、动态图片解码器、GIF/H.264 导出栈和 AI 组件桥接。桌面左栏 420px 独立滚动，舞台按自身尺寸居中；手机舞台和时间轴在控制栏上方。

内容页支持共享 Flow、动态矢量、13 个 GIF、59 个动物头像、Bots 和上传 SVG/图片/GIF。先选择再插入，不自动展开已选管理；单独编辑会暂停并定位到当前素材可见的时刻。可调尺寸、透明度、旋转、位置、名称/文字、字体、颜色、图文间距，替换素材保留已有参数。动物页可把选中素材作为品牌图标。专利墙第一张为翻转封面，其余作为证书池。

动画页按可见阶段调整时长，支持速度、循环、方向、整体位置与大小；动物页另有头像间距和波幅，Bot 页有胶囊宽度。阶段时长通过原生时间的连续映射生效，保留阶段内部原曲线及交叠。

方案包含保存、导入、恢复默认、清理重做与撤销重做。背景支持图片、GIF、视频，视频有六帧预览和开始/结束裁切。输出尺寸和时长可选，支持 PNG、GIF、MP4；导出从目标尺寸重绘。AI 菜单可预览组件、复制提示词/配置代码、下载组件 JSON、查看参数说明。
