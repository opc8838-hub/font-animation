# 三段存档动效接入 CellMotion

用户提供的三段存档已接入官网统一编辑器。原目录保留不变。

| 编辑器 | 画幅 / 单轮时长 | 内容 |
| --- | --- | --- |
| [Bot 语音](../site/botvoice.html) | 1080×1920 / 11.8s | 手机按键、Bot 入屏与飞行、流动方块、语音胶囊 |
| [专利墙](../site/patentwall.html) | 1920×1080 / 15.815s | 翻转封面、作品展开、四张特写、作品墙 |
| [动物浪潮](../site/animalwave.html) | 1920×1080 / 11s | 头像递增、加速成浪、品牌收尾 |

三个页面共用 `cardmotion-editor.js`、字体与图标库、动态图片解码器、GIF/H.264 导出栈和 AI 组件桥接。桌面左栏为 420px 独立滚动区，舞台按自身尺寸居中；手机舞台与时间轴在控制栏上方。

## 内容编辑

动物浪潮的每个头像均可替换，头像名称/文字逐项可编辑。首句、递增句、品牌文字可修改；递增句支持 `{count}` 当前总数、`{shown}` 已出现头像数、`{n}` 新增数、`{name}` 当前头像名。已有数量和每个头像的增量可设，字幕可在「头像名＋文案」与「仅文案」间切换，适合关注数等内容。方形与非方形上传头像统一居中裁切为圆形。

专利墙的翻转封面与 195 张墙面作品均取自 `D:\mutedmen`，分别使用不同图片，资源经过压缩以便网页加载。开场、四张特写与墙面仍使用原参考动效的镜头和节奏；图片内容不重复。白色为默认动效背景，同时开放背景颜色及图片/GIF/视频替换。图片上的原生文字属于图片像素，编辑器提供可编辑的附加文字。

Bot 语音保留原动效，但与另外两段共享 CellMotion 的方案、素材、UI、For AI 和导出能力。三段均支持阶段时长、速度、循环、画幅、位置与大小，方案保存/导入/恢复默认/清空/撤销/重做，以及 PNG、GIF、MP4 输出。For AI 组件预览携带当前配置并使用同一渲染器。

## 验收

`node scripts/test-archive-motion.cjs [playwright 包路径] [Chrome 路径]` 已通过三段回归：默认方案、阶段渲染、中文 PNG、1s GIF 时长、重置、桌面居中、手机布局、共享矢量/GIF、For AI 预览。专利墙额外验证 196 个默认资源 ID 唯一；动物浪潮验证关注数和纯文案编辑会改变预览。浏览器无控制台错误。专利墙还生成了 640×360 完整循环 MP4，媒体元数据为 15.833s，并重做了同尺寸画廊封面。其余两段已在初次接入时完成原生 PNG/GIF/MP4 和完整预览验收。

原视频的 FFprobe、FFmpeg 抽帧与阶段记录见 [Bot 语音](analyses/botvoice.md)、[专利墙](analyses/patentwall.md)、[动物浪潮](analyses/animalwave.md)。

## 细节边界

专利墙更换为作品图后，原证书的逐字遮罩不再适用于新图；四段特写保留原停留时长，作品图整张呈现。MP4 时长按整帧量化，专利墙 30fps 为 475 帧 / 15.833s。
