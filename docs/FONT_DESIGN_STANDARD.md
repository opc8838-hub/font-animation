# CellMotion 字体设计与交付规范

适用于新建字体、引入字体及字体试样页；动效编辑器继续遵守现有三栏与导出规范。

## 先定义交付类型

- 字样：为某几个字或一个词设计的图形，不宣称支持任意输入。
- 字体：字符映射、字形、度量和命名完整，可输入声明范围内的文本。
- 字体家族：同一设计逻辑下有明确的样式、真实字重或可变轴。单字重字体可以完整，但不能把三个展示词称为三个字体体系。
- 引入字体：保留原字形、名称、版本、来源与版权。新增展示或动画不等于重新设计了字体。

每次先写明字符覆盖、字体家族目标、字重数量、使用场景及输出格式。原创字体若要求多个字重，先设计 Regular，再确定 Light/Bold 的骨架、笔宽与补偿；不要使用浏览器合成粗体冒充交付。

## 字形与度量

1. 明确 UPM、基线、x-height、cap-height、升部、降部、overshoot、行距。字体设计单位与 CSS px 分开标注。已有字体缺失的度量保留“未记录”；从 H/x 测量的墨迹边界单列，不冒充原生 OS/2 元数据。
2. 建立一组能检验设计逻辑的控制字，如 H/O/n/o/a/e/g，确定粗细对比、圆弧、末端、重心和内白，再扩展字符集。
3. 同源设计字形、笔触和异体。粗字重逐字检查字腔、连接部位、窄字宽度、侧距；细字重检查细节可见性。单纯向外描边或横向缩放不能代替完整字重设计。
4. 先处理 advance width、左右侧距与空格，再检查 AV/VA/To/Ta/Wa/Yo 等组合是否需要 kerning。字符间距、词间距、行高分别建模，不用全局 letter-spacing 掩盖局部字偶问题。
5. 明确 Unicode 映射和缺字行为。区分字符数、映射数、字形数以及异体字形数；组合字符、标点、空白和缺字框也属于验收范围。

## 文件与能力清单

每份字体记录：家族名、样式名、PostScript 名、版本、真实字重、设计者/来源、版权/许可、文件格式、字形与字符覆盖、度量、OpenType 特性和可变轴。

清单从字体文件或同一次构建生成，页面读取同一来源。静态 300/400/700 三份字体不是连续可变字体；没有 `fvar` 轴就不提供连续轴声明。不存在的斜体、异体或 kerning 不显示为可用能力。

`scripts/inspect-font.py` 可抽取现有文件的基础规格。它不修改字体，也不推断缺失的设计参数。

## 字体试样页

- 自由输入、多行试字，字号带 px 单位，提供真实字重、字距/em、行高/倍控制。
- 仅一个真实字重时清楚显示该字重；不要提供虚假的 Light/Bold 按钮。
- 白底试样与纸纹/特效样张分开；同时观察字号阶梯、大小写、数字、标点、连续重复字母、长短词及多行段落。
- 字号阶梯至少覆盖 16/24/36/48/72/120 px；这是试样测试点，不代表每种字体都适用于正文。
- 特殊样张若使用倍率或移动端字号上限，标注实际字号。自动适配后的显示尺寸不能继续冒称输入字号。
- 实际报告回退字符；回退字体显示出的中文不能计为原字体的中文覆盖。
- 有相应特性时才提供 OpenType/可变轴控制，并验证切换确实影响字形。

## 动态字体

区分字形变化、书写动画和整块排版动画。整块淡入淡出不代表字体具有笔顺或动态异体。

采用异体切帧时，各帧须维持相容的 advance、布局与基线；预览和导出使用同一时间规则。采用笔顺动画时须有真实笔画数据，不能从任意轮廓顺序推断书写顺序。静态、减少动态偏好及导出帧均须可读。

## 验收与版本

- 核对 `name`、`cmap`、`hmtx`、`OS/2`、`head` 与已声明的特性/轴，测试 .notdef、重复字、标点、易混字符和长短文本。
- 在小、中、大字号检查破口、轮廓自交、闭合字腔、重叠、裁切与行距。检查不同字重的整体颜色和局部内白，而非只比较一个大标题。
- 原创构建固定随机种子、版本及必要时间戳；验证同输入能复现产物。对引入字体比较原文件与 Web 字体的映射和轮廓，不改动来源资产。
- 导出后的图像/视频须验证字重、换行、字距、行距与预览一致。每次只声明实际验证的能力。

学习来源与本次差距见 [Z1 Scrawl 对照记录](analyses/z1-scrawl-review.md)。这些规则不要求把某一个项目的视觉风格复制给所有字体。
