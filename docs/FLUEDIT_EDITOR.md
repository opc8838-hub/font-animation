# 流彩 Fluedit · CellMotion 编辑器

入口：`fluedit/`，兼容入口为 `fluedit.html`。组件库、编辑器目录和首页最近上新共用 `gallery.js` 与生成的 `cellmotion-catalog.json`。

基础形状与色彩渲染来自用户指定的 https://fluedit.vercel.app/ 。本次适配保留其八种形状、渐变色标、局部色区、色谱预设和流动算法，将产品界面接入 CellMotion 的三栏工作台。

## 界面与状态

- 左侧：形状选择、预设色谱、保存/导入/恢复默认/清理重做四项方案操作。
- 中间：左上角沿用 CellMotion 的“铺满背景”弹层，右侧为紧凑画幅选择；下方是实际构图、播放/暂停/重播和可拖动的色彩时间轴。色彩流动、色谱偏移和色域呼吸使用独立颜色的并行轨道。衬底偏好沿用全站存储键，跟随当前形状背景或使用独立颜色，不进入作品和导出。
- 右侧：色彩编辑、动效设置、导出三个属性面板；桌面侧栏独立滚动。移动端顺序为画布、形状与方案、属性。
- 使用共享 `typecascade-workspace.css`、`typecascade-polish.css`、`typecascade-selects.js` 和 `site-preferences.js`。主题与中英语言沿用站内偏好；UI 偏好不进入作品像素。
- `cellmotion-editor.js` 负责界面和工作台状态；`cellmotion-locale.js` 负责本页双语文案；基础模块尾部提供渲染与状态适配接口。
- 每种形状分别保留色谱、色区和动画配置。方案 JSON 包含全部已编辑形状、当前形状、画幅与导出参数。普通刷新恢复本机修改，`?from=gallery` 打开不可变默认示例。
- 默认示例会自动播放：流动速度 81%、幅度 100%、色谱偏移范围 68%，约 4.86 秒完成一轮亮暗变化。打开新形状、切换色谱与恢复默认均保留这一运动；系统“减少动态效果”偏好下暂停自动播放，仍可主动播放。旧版完全未编辑的静态默认记录自动升级；旧弱流动配置即使调过速度也补齐可见的色谱偏移，保留修改过的速度、配色和背景。视频观察见[运动分析](analyses/fluedit-motion.md)。
- 恢复默认返回默认蝴蝶示例和 16:9 画幅；清理重做将当前形状恢复为黑白双节点色谱，清除色区和动画，保留内置形状。

## 渲染与导出

画布支持预设和自定义尺寸；形状保持原始比例，在选择的构图内居中完整显示。背景颜色同时用于预览与导出。预览和离屏输出调用同一 WebGL 渲染器与同一时间参数。

PNG 输出当前帧；GIF 和 H.264 MP4 从零开始按所选时长与帧率输出。使用仓库内 `continuation-gif.js` 和 `h264-mp4-encoder.web.js`，不依赖第三方在线编码服务。GIF 的百分之一秒延迟在帧间分配，避免 15 FPS 累积时长误差。基础流动周期由流动速度计算；可另选固定或自定义时长。可选输出比例明确显示最终像素尺寸。

2026-10-23 浏览器检查覆盖形状/色谱切换、三条动画轨道、暂停与拖动、明暗主题、中英切换、画幅切换、方案导出/导入/刷新恢复，以及 PNG/GIF/MP4 实际编码。检查宽度为 320、390、1024、1440；桌面没有整页溢出，手机没有横向溢出。实际导出包含 320×480 竖版；MP4 为 H.264、15 FPS、15 帧、1 秒。

可重复执行的浏览器回归检查为 `tests/fluedit-browser.cjs`。先将 `site/` 作为静态目录启动本地服务，再执行 `node tests/fluedit-browser.cjs <包含 playwright 的 node_modules 目录> <浏览器可执行文件> [服务地址] [输出目录]`。测试产物包含方案、预览截图和三种实际导出文件。

默认动画回归检查为 `tests/fluedit-motion-browser.cjs`，参数格式相同。它验证默认实际像素变化、暂停/重播、切换形状与色谱、旧默认升级、用户静态作品保留、减少动态效果和真实动画导出。`tests/fluedit-legacy-motion-browser.cjs` 专门验证旧版已播放配置在保留自定义色值和背景时升级，并比较自动播放中的实际画布像素；时间前进本身不作为画面运动的证明。`assets/previews/fluedit-card.mp4` 是同一渲染器输出的 768×432、30 FPS、292 帧基础周期，经 H.264 压缩为约 589 KB；用于首页、组件库与编辑器目录。

## 用于 AI / For AI

标题栏复用共享 `cellmotion-ai-menu.js` 的五项菜单：组件预览、复制 AI 提示词、复制配置代码、下载组件 JSON、参数说明。定义为 `effects/fluedit.component.json`，包含 43 个参数路径。

实时 Manifest 的 `composition.scene` 保存当前完整作品，`documents` 保存其他已编辑形状，`canvas` 是逻辑画幅和帧率，`settings` 保留导出设置。保留现有编辑器方案格式，不用 DOM 控件快照代替真实状态。共享参数 Schema 的 scene 内容模型可直接承载此数据。

共享播放器通过 `CellMotionBridge.register` 配置原始 WebGL 渲染器，支持播放、暂停、重播、定位、时长和实时更新。`?preview=1&embed=1` 隐藏编辑器外壳；预览不读写作品自动保存，不把编辑区衬底或主题带入画面。嵌套目录下的组件定义、演示页、Schema 和播放器脚本均从站点根目录解析。

`tests/fluedit-standard-browser.cjs` 覆盖八种形状的真实连续像素变化、旧速度保留、独立衬底、画幅比例、实时 Manifest、菜单/剪贴板、真实组件预览、编辑器/播放器像素对比、独立来源站点粘贴代码、桥接版本拒绝和移动端布局。

本地验证达到 Verified：编辑形状、色标、局部色区、背景和 320×480 画幅后，Manifest 与真实播放器还原当前状态；相同时刻画布采样平均通道差约 1.12/255。预览播放/暂停/重播/定位/实时更新、跨来源粘贴代码、错误来源/非父窗口/错误版本消息拒绝、自动保存隔离、中英主题及 320/390/1024/1440 布局均通过。原编辑器完整回归和三种实际导出也通过。
