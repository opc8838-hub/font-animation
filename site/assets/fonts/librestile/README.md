# Librestile and CellMotion Square

Upstream: https://github.com/ocelothe/Librestile (ocelothe2k1).
Both files are distributed under the accompanying SIL Open Font License 1.1.

- `librestileextbold.woff2`: unmodified upstream Extended Bold.
- `cellmotion-square.woff2`: renamed derivative, CellMotion Square. The capital O
  uses a rounded rectangular outer contour and counter to match the square
  metallic lettering; all other glyphs retain the upstream shapes. Regenerate
  with `scripts/build-metallic-square-font.py` and the upstream TTF.
