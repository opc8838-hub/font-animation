The page also reuses the project's existing Snap assets (`Inter-Medium.ttf` and
`SpaceMono-Bold.ttf`). Satoshi, General Sans, Clash Display, and Cabinet Grotesk
are not copied into this repository; they are delivered by the official
Fontshare CSS API under Fontshare's web-use terms.

Apoc was listed by the historical Snap interface but is intentionally omitted:
an unambiguous redistribution license and original font file were not present in
the project.
