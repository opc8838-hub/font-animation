# 参与贡献 / Contributing

CellMotion welcomes bug reports, focused feature proposals, and code contributions. You can write in Chinese or English. Please search existing issues and pull requests before opening a new one.

## 提交 Issue

1. 在仓库顶部打开 **Issues → New issue**，选择 **Bug report** 或 **Feature request**；也可以直接点[新建 Issue](https://github.com/opc8838-hub/font-animation/issues/new/choose)。
2. **Bug report** 请写清：效果页或编辑器链接、浏览器和设备、复现步骤、实际结果与预期结果。能稳定复现的中文输入、画幅、导出问题也请注明。
3. 附上相关截图或短录屏；如果有浏览器控制台错误，请复制错误文本。不要上传密码、令牌或私人素材。
4. **Feature request** 请描述要解决的问题、期望行为和使用场景；参考图或参考视频有助于判断，但请确认你有权分享。

## 提交 Pull Request

1. 从最新 `main` 创建一个有明确主题的分支；外部贡献者先 Fork 本仓库，再从自己的分支提 PR。
2. 让一个 PR 只处理一项相关改动，并关联对应 Issue（例如 `Closes #123`）。
3. 在 GitHub 打开 **Pull requests → New pull request**，选择目标为 `main`，填写 PR 模板后提交。
4. 描述要包含：改了什么、为什么改、如何验证。界面改动附桌面与手机截图；动效改动列出播放和导出检查结果。
5. 保留第三方署名和许可。新增字体、图片、视频或其他大文件时，请注明来源及使用许可；不要提交密钥、个人信息或无权发布的素材。

## How to open an issue

1. Choose **Issues → New issue** and select **Bug report** or **Feature request**, or use the [issue form](https://github.com/opc8838-hub/font-animation/issues/new/choose).
2. For a bug, include the effect/editor URL, browser and device, exact reproduction steps, actual and expected results, and whether Chinese text, a specific canvas size, or export is involved.
3. Add a screenshot or short recording when useful. Include relevant browser-console errors as text. Never include passwords, tokens, or private assets.
4. For a feature request, explain the problem, the desired behavior, and who would use it. Share reference media only when you have permission to do so.

## How to open a pull request

1. Create a focused branch from the latest `main`. Contributors outside the repository should fork it and open a PR from their fork.
2. Keep each PR to one related change and link its issue (for example, `Closes #123`).
3. Open **Pull requests → New pull request**, target `main`, complete the PR template, and submit it for review.
4. Describe what changed, why, and how you verified it. Include desktop and mobile screenshots for UI work; list playback and export checks for motion work.
5. Preserve third-party attribution and licenses. For added fonts, images, videos, or other large files, state the source and usage rights. Do not commit secrets, personal information, or assets you cannot publish.
